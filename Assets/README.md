# Password Generator: Logo und Icon

Erstellt am 28. September 2026 mit der eingebauten Imagegen-Funktion von Codex. Beide PNG-Originale besitzen einen transparenten Hintergrund. Das Icon enthält eine dunkelblaue Kachel; das separate Logo enthält nur das mintgrüne und silberne Schlüsselsymbol. Sechs Segmente im Schlüsselring greifen die sechs SHAKE-Ströme gestalterisch auf.

Die Originalvorlagen liegen in `PasswordGeneratorIcon.png` und `PasswordGeneratorLogo.png`. Das Buildskript erzeugt die macOS-Icongrößen aus der Iconvorlage. Die App nutzt das separate Logo in der Kopfzeile.

## Prompt für das Icon

Use case: logo-brand. Create a single polished macOS application icon and reusable brand symbol for an offline Password Generator. Square composition 1024x1024 with real transparent pixels around an inset rounded-square dark navy tile, safe margins about 9%. A bold, elegant, easily recognized geometric key in luminous mint and cool silver, its circular bow formed by six precisely fitted simple segments, suggesting six combined streams of randomness. The shaft points diagonally down-right and has two crisp teeth. Calm premium native macOS utility aesthetic, subtle depth and restrained highlights, beautifully balanced at 32px as well as 1024px. Keep large simple shapes, high contrast, smooth clean edges. No text, no letters, no digits, no padlock, no shield, no background scene, no watermark, no extra objects. The whole icon must be centered and fully visible.

## Prompt für das separate Logo

Use case: background-extraction. Asset type: reusable standalone logo symbol for Password Generator. Edit the reference icon: remove the complete dark navy rounded square tile, all tile shadows and any navy filling in the key ring's central hole, leaving only the identical six-segment mint-and-silver key symbol on a genuinely transparent background. Preserve the key's geometry, colors, materials, orientation and six distinct ring segments exactly. Keep comfortable transparent margins on a square canvas. No text, no replacement background, no new elements.
